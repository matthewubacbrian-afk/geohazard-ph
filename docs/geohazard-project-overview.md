# GeoHazard PH - Project Overview

This document belongs to the versioned project docs. The original root-level reference file remains available while the repo is being scaffolded.

GeoHazard PH aggregates public earthquake, volcano, fault, and ground movement data into a web and mobile platform for awareness and preparedness in the Philippines.

Core v1 scope:

- Real-time earthquake monitoring from USGS and PHIVOLCS-derived data.
- Volcano activity tracking from GVP and PHIVOLCS bulletins.
- Active fault reference layers.
- Location-based alerts.
- Map-based web dashboard and mobile quick-glance app.
