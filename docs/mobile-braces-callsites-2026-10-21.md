# Mobile `braces` consumer calls — 2026-10-21

This bounded review concerns [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm): deeply nested brace patterns can exhaust the Node.js call stack in `braces` through 3.0.3. It records calls in the pinned React Native 0.75.5 production dependency graph and separately notes development-only consumers. It is not an end-to-end attack path or a device-runtime finding. The final [PR #59](https://github.com/matthewubacbrian-afk/geohazard-ph/pull/59) Android/iOS Release reports still contain 34 audit-chain findings each, all **undetermined**.

## Exact sources and dependency edges

`mobile/package-lock.json` resolves `braces` 3.0.3 only through `micromatch` 4.0.8. Four production-graph packages directly declare `micromatch`: `fast-glob` 3.3.3, `metro-file-map` 0.80.12, `jscodeshift` 0.14.0, and `jest-message-util` 29.7.0. Four additional direct consumers are marked `dev: true` in the lockfile: `@jest/core`, `@jest/transform`, `jest-config`, and `jest-haste-map` (all 29.7.0). Four React Native CLI packages directly declare `fast-glob`: `cli-platform-android`, `cli-platform-apple`, `cli-clean`, and `cli-config` (all 14.1.0). These are dependency edges, not execution traces. The published tarballs for these 14 packages were checked against their lockfile SHA-512 integrity values before inspection.

[`micromatch` 4.0.8](https://registry.npmjs.org/micromatch/-/micromatch-4.0.8.tgz) imports `braces`, but its ordinary matching methods (`micromatch()`, `some`, `isMatch`, and `any`) call `picomatch`. Its `parse` and `braces` methods call the `braces` package; `braces(pattern)` returns the input unchanged when the string has no paired `{` and `}`. [`fast-glob` 3.3.3](https://registry.npmjs.org/fast-glob/-/fast-glob-3.3.3.tgz) defaults `braceExpansion` to true and passes input and ignore patterns through `micromatch.braces(..., {expand: true})` while generating tasks. That is the observed bridge to the advisory's recursive brace processing when a pattern contains braces.

The CLI call sites above cover the published direct `fast-glob` imports found in the inspected 14.1.0 packages. They do not prove a reachable attacker can supply a sufficiently deep pattern to `fast-glob`, nor do they exclude other indirect calls, environment-controlled temp paths, build-tool inputs, or future consumers. The Release source maps and native-file inventories cannot establish that `braces` runs in the distributed Android or iOS app. The `braces` advisory and all 34 audit finding dispositions remain **undetermined** pending a full input and execution-path review.

## Reproduction

From `mobile/`, run `npm ls braces micromatch fast-glob --omit=dev --package-lock-only --all --json` to reproduce production paths, then omit `--omit=dev` to include the four supplemental development consumers. Compare the published tarballs' SHA-512 digests with `mobile/package-lock.json`, then inspect `micromatch/index.js`, `fast-glob/out/managers/tasks.js`, `fast-glob/out/utils/pattern.js`, and the consumer files named above. A subsequent review must establish any untrusted pattern entry point, its path to the affected `braces` operation, and whether that operation executes in a build, development tool, or device process before changing a disposition.
